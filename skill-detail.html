Memory Hot-Swap 插件

实现 AI 记忆的热插拔功能，支持动态切换记忆存储后端

★★★★★
⭐ 4.8 (1.2k 下载)
📦 安装命令
openclaw plugin install memory-hotswap
⚙️ 配置参数
参数 类型 默认值 说明
backend string "sqlite" 记忆存储后端：sqlite、redis、memory、postgres
max_size number 10000 最大记忆条数（0=无限制）
ttl number 86400 记忆存活时间（秒，默认24小时）
flush_interval number 60 刷盘间隔（秒）
📖 使用示例
// 配置 memory-hotswap 插件
{
  "plugins": {
    "memory-hotswap": {
      "backend": "sqlite",
      "max_size": 50000,
      "ttl": 86400,
      "flush_interval": 60
    }
  }
}

// 运行时热切换后端
openclaw plugin memory-hotswap switch --backend redis
🌟 功能特点
  • ✅ 热插拔: 不用重启服务即可切换记忆存储
  • ✅ 多后端支持: SQLite、Redis、PostgreSQL、内存
  • ✅ 自动刷盘: 定期持久化防止数据丢失
  • ✅ TTL管理: 自动清理过期记忆
  • ✅ 性能监控: 提供命中率、延迟等指标
